## 字体简介

“玉生花侠义行书”风格粗犷豪迈、刚劲有力，兼具行书的流畅连贯与碑刻般的金石厚重感，其横画微翘、竖画挺拔、撇捺舒展且带有明显的刷痕与飞白质感，整体视觉极具张力、速度感与强烈的江湖武侠气韵。

在行业应用方面，非常适合应用于游戏娱乐（尤其是武侠、仙侠、历史题材的MMORPG或动作手游）、影视动漫宣传海报、文创周边、国潮品牌视觉识别（VI）、音乐专辑封面、特色餐饮零售包装以及现代书法艺术衍生品等领域。

在具体使用场景上，“玉生花侠义行书”由于辨识度极高且视觉冲击力强，极为契合大型活动的视觉主标题、影视宣发海报的大号标语、游戏内技能名称与胜负结算界面、电商大促的狂欢文案、实体图书与国风漫画的封面书名，以及各类需要展现力量感、速度感、传统文化底蕴或不羁个性的品牌展陈与空间导视系统，能够瞬间抓住受众眼球并营造出浓厚的情感氛围。

## 使用须知

本字体目前实现GB2312字符集的3755个中文字符，不包含英文字母、数字、标点符号。部分字形跟标准字形不一致。

缺失字符列表请查看 missing_chars.txt。

计划每隔一段时间，更新补全一批字符，直至完成GB2312字符集所有字符。

## 关于玉生花字库

一直很喜欢艺术，总想在艺术领域做点真正有价值的事。但在刷了无数艺术类内容后，我发现很多赛道早已变了味，充斥着博眼球的套路与浮躁，这让我觉得很不适，也一度很迷茫。

兜兜转转一圈，我把目光投向了字体设计。这是一个极其冷门、甚至有些枯燥的领域——这里没有流量密码，只有成千上万个汉字的枯燥打磨，安静得让人安心。

我本人是技术出身，在做字库的过程中，我尝试引入各种技术手段来辅助设计、提升造字效率。我越来越觉得，现代字体制作，本质上是“理性技术”与“感性艺术”的结合，更是一场需要耐得住性子的工匠修行。

玉生花字库的所有字体，均由主理人：亦也 亲自操刀设计制作。

“玉生花”这三个字，对我有着特殊的意义：它既是我魂牵梦萦的故乡，也是我现在扎根定居的城市。把人生的归处写进品牌的名字里，也是希望我的每一套字，都能像故乡一样真诚，像生活一样耐看。
